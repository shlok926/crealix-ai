# Security Policy

## Supported Versions

The following versions of **Crealix AI** currently receive security updates:

| Version | Supported |
| ------- | --------- |
| 2.x.x   | :white_check_mark: |
| < 2.x.x | :x: |

## Reporting a Vulnerability

We take the security of this project seriously. If you find a security vulnerability, please do not report it publicly via GitHub issues. Instead, please report it in one of the following ways:

1. **Private Vulnerability Reporting**: Go to the **Security** tab of this repository on GitHub and select **Report a vulnerability** under "Private vulnerability reporting".
2. **Email**: Contact the repository maintainer directly at the email listed on their GitHub profile.

Please provide a detailed description of the vulnerability, including steps to reproduce it and a proof of concept if possible. We will acknowledge receipt of your report within 48 hours and work to resolve the issue promptly.
